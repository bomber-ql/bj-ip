# GEO 文章写作规范

适用于全域智能洞察栏目的所有文章。目的不是"多写关键词"，而是让内容**能被 AI 切片引用、被搜索引擎判定为高质量**。

两条底层逻辑：

- **SEO 关心**：这页有没有独特价值、结构是否清晰、能不能承接某个搜索意图
- **GEO 关心**：这段文字能不能**脱离上下文独立回答一个问题**

后面所有要求，都是为这两条服务的。

---

## 一、必备结构（8 个模块）

一篇文章必须按顺序包含以下模块。缺任何一个，判定为不合规。

| # | 模块 | 作用 | 字数 |
|---|---|---|---|
| 1 | **一句话答案** | 开篇直接回答标题提出的问题 | 40–80 字 |
| 2 | 本文要点 | 目录，可跳转 | 自动生成 |
| 3 | 导语 | 说清写给谁、解决什么问题 | 80–150 字 |
| 4 | 正文分节 | 每节一个 H2，用**问句或判断句** | 3–8 节 |
| 5 | **对比表格** ≥1 | 方案/阶段/工具的横向对比 | 3 行以上 |
| 6 | **数据表或清单** ≥1 | 具体数字，带单位 | — |
| 7 | **FAQ** 5–8 条 | 用户真实会问的问题 | 每条 50–120 字 |
| 8 | **品牌观点** | 我们自己的判断，带署名 | 150–300 字 |
| 9 | 相关服务内链 | 自然嵌入，不硬塞 | 1–2 条 |

### 1. 一句话答案

放在 H1 之后、本文要点之前，用 `.tldr` 包裹。

```
<div class="tldr">
  <p>医美小会不是"把发布会做小"，而是把预算集中在二十个最可能成交的人身上……
</div>
```

要求：**不看下文也能拿走一个结论**。AI 引擎最常引用的就是这一段。

### 2. 正文分节：H2 必须是问句或判断句

| ❌ 不合格 | ✅ 合格 |
|---|---|
| 一、市场调研 | 开一个新市场，先看哪三个数？ |
| 二、视觉锤系统 | 为什么你的 LOGO 记不住？ |
| 三、内容生产 | 一个月产 30 条内容，靠的不是灵感 |

原因：用户搜的是问题，不是章节名。问句 H2 直接匹配 query，也是 AI 抽取时的天然边界。

每节开头**先给结论**，再展开。不要"首先……其次……最后"这种空转。

### 3. 对比表格

GEO 里性价比最高的一种结构——AI 抽取表格的准确率远高于抽取段落。

必须满足：
- 至少 3 行
- 有表头，第一列是对比维度
- 单元格里是具体值，不是"较好/较强"

```
<table class="geo-table">
  <thead><tr><th>对比项</th><th>医美小会</th><th>大众投放</th></tr></thead>
  <tbody>
    <tr><td>单场成本</td><td>3–8 万</td><td>20 万起</td></tr>
    <tr><td>触达人数</td><td>15–30 人</td><td>10 万+ 曝光</td></tr>
  </tbody>
</table>
```

### 4. 数据表或清单

数字必须具体。"服务过很多客户"是废话，"服务过 200 家企业"才是信息。

有出处的标出处（艾瑞、乘联会、平台财报等公开报告）。拿不到出处的，明确写"内部项目数据"，不要伪造来源。

### 5. 品牌观点（软文的"声音"）

这是软文和通用指南的分界线。前四节讲的是"行业怎么做事"，这一节讲的是"**我们怎么想**"。

要求：
- 一个明确、可以被反驳的观点（不是"要重视用户体验"这种正确的废话）
- 说明这个观点会带来什么不同的动作
- 带署名：`— 怡亚科技 · 品牌活动团队`

```
<div class="brand-view">
  <p>我们的看法是：医美小会不是一场活动，而是一次名单的重新激活……</p>
  <span class="attr">— 怡亚科技 · 品牌活动团队</span>
</div>
```

为什么必须要有：AI 引用中立内容时不会提品牌，引用**带署名的观点**时会把品牌一起带上。这是 GEO 里建立"品牌 = 某个观点"关联最直接的方式。

判断标准：把品牌名去掉，这句话仍然成立，但**换一家公司说不出来**——那才是观点。

### 6. FAQ

5–8 条，问法要贴近真实搜索：

- ✅ "医美小会一场要花多少钱？"
- ❌ "医美小会的成本效益分析"

FAQ 会同时输出 `FAQPage` 结构化数据，是争取搜索结果富摘要的主要手段。

## 二、写作层面的四条硬规则

**① 定义句开头**

每个核心概念第一次出现时，用"X 是指……"的句式定义一次。这是 AI 抽取定义的标准格式。

> 视觉锤是指一个品牌在视觉上可被瞬间识别的固定元素，通常由颜色、形状、字体三者中的一到两个构成。

**② 数字替代形容词**

| ❌ | ✅ |
|---|---|
| 丰富的行业经验 | 平均 8 年从业经验 |
| 大量成功案例 | 累计交付 500+ 内容项目 |
| 效果显著提升 | 咨询转化率从 3.2% 提升到 5.8% |

**③ 禁用 AI 腔**

删掉这些词：赋能、闭环、抓手、生态位、底层逻辑（除非真的在讲逻辑）、首先/其次/最后、综上所述、值得注意的是、在这个快速变化的时代。

**④ 每段不超过 4 行**

手机上一屏能读完一段。长段落既不利于阅读，也不利于 AI 切片。

## 三、技术标记要求

| 要求 | 说明 |
|---|---|
| 表格用 `<table class="geo-table">` | 已内置响应式样式 |
| 一句话答案用 `<div class="tldr">` | 视觉上是一个浅色块 |
| FAQ 用 `<div class="geo-faq">` + `<details>` | 自动生成 FAQPage schema |
| 图片必须有 alt | 生成器自动补 |
| H2 自动加锚点 | 生成器自动加，用于本文要点跳转 |
| 内链锚文本要描述性 | "品牌策略与设计" 而不是 "点击这里" |

## 四、上线前自检

### 第一步：跑体检

```bash
python3 scripts/geo-lint.py          # 全部文章
python3 scripts/geo-lint.py geo-kpi  # 只查文件名含 geo-kpi 的
```

它会逐篇检查下面 10 项，输出分数：

1. 有没有一句话答案
2. 有没有对比表格
3. 有没有品牌观点（`.brand-view`）
4. 有没有数据表/清单
5. FAQ 是否 ≥5 条
6. H2 问句比例是否 ≥50%
7. 是否含定义句（"是指"/"指的是"）
8. 具体数字密度（每千字 3 个以上）
9. 是否有 AI 腔词汇
10. 有没有内链到服务页

**满分 100，80 分以下不建议发布。**

报告末尾还会单独输出「排版提醒」（半角引号、中文后半角标点），不计分，但建议清零。

### 第二步：挂进构建流程

新文章要加两处，否则不会出现在任何列表里：

1. `scripts/build-articles.py` 的 `SLUG` 映射里加一行，如 `"geo06": "geo-xxx"`
2. `articles-index.json` 里加一条，字段照抄现有条目（`id` 要和 slug 映射的键一致）

标题控制在 **32 字以内**（含「 - 怡亚科技」后缀），超了 `seo-audit.py` 会报质量项。

### 第三步：构建

```bash
python3 scripts/build-articles.py
```

一次会更新：文章页、列表页 `insights.html`、`sitemap.xml`、`sitemap.html`、`llms.txt`。

### 第四步：跑全站审计

```bash
python3 scripts/seo-audit.py
```

看两个数字：**红线项必须 0**，质量项尽量压到 0（剩下的通常是标题字数这类内容问题）。

### 第五步：看渲染

文章页容易出问题的地方只有三处，重点看这三处就够：

- **表格首列**：窄屏下短标签会不会被压成两行（如"品类词（必争）"→"品类词（必 / 争）"）
- **表格右侧**：手机上是否溢出了却有横滑提示（靠内阴影）
- **长标题**：H2 在 375px 宽下会不会把最后一个字挤到下一行

### 第六步：部署后再推百度

**顺序不能反。** 推送前先确认线上已经能打开：

```bash
curl -s -o /dev/null -w "%{http_code}\n" https://www.bj-ip.com/insights/<slug>.html
```

返回 **200** 才推；返回 **404** 说明还没部署，此时推送会让百度记一次抓取失败。

```bash
python3 scripts/baidu-push.py <token> "关键词"
```

脚本会从 `sitemap.xml` 里按关键词筛 URL，打印每批成功数与剩余配额。每天配额有限，别重复推同一批。

## 五、为什么这么做

传统 SEO 的思路是"覆盖更多关键词"。GEO 的思路正相反：**让每一段都值得被单独引用**。

一个具体的对比：

| | 传统写法 | GEO 写法 |
|---|---|---|
| 开头 | "在当今数字化时代，品牌营销面临……" | "医美小会一场 3–8 万，比投 20 万信息流更划算——前提是你有 20 个精准名单。" |
| 结构 | 一、二、三 章节名 | 每个标题是一个问题 |
| 证据 | "效果很好" | 表格 + 数字 + 来源 |
| 结尾 | "综上所述……" | FAQ 8 条 |

AI 不会引用前者，因为它没有可引用的事实。它会引用后者，因为每一句都能独立成立。


**5. 中文标点必须用全角。** 引号用「」或“”，逗号句号用，。不要出现半角 `"` `,` `.`。混用是中文排版里最容易被一眼看出的不专业——它不是风格问题，是校对没做。`scripts/geo-lint.py` 会在报告末尾提示，不扣分但建议清零。
